# Historical return verification


MANDATORY HISTORICAL RETURN CORRECTION — overrides any conflicting earlier instruction or examples.
Apply to every 30D and 1Y field for Singapore stocks, global indices and precious metals.
Never reuse returns or endpoint prices from prior briefings, prompt examples, search snippets, undated quote panels, 52-week ranges, or provider performance widgets.
Use the instrument's last fully completed exchange session before the information cutoff as endpoint T. Anchor both lookbacks to that session date, not today's briefing date. 30D means T minus exactly 30 calendar days (not one month); 1Y means the same calendar date one year earlier (February 29 maps to February 28). Select the last actual trading session on or before each target in the instrument's exchange calendar. Record target dates and actual dates. Never use a session after the target.
For equities use the same named historical series and price field at all endpoints. Default to closing prices adjusted for splits/bonus/consolidations only, excluding cash-dividend reinvestment: explicitly label PRICE RETURN. Audit corporate actions; do not assume a generic Adjusted Close field excludes dividends. If a dividend-adjusted series is deliberately used, label its precise provider methodology and TOTAL RETURN PROXY rather than price return. Do not mix raw latest close with adjusted historical prices. An unresolved corporate action or adjustment definition makes that return Unavailable.
For indices use the exact cash PRICE index, not ETF, futures, total-return variant or a different Nasdaq index. For metals use the same spot benchmark/fixing and comparable observation times and units; otherwise Unavailable.
Retrieve complete dated rows from the original historical table or downloadable dataset. Keep a calculation evidence table with instrument/ticker, currency/unit, endpoint T/date/value, target and actual reference dates/values, field, adjustment methodology, source URL and retrieval time.
Independently corroborate each endpoint against a second reliable provider or official exchange/index data. Apparent mirrors of one feed are not independent checks. Reconcile discrepancies exceeding the instrument's published rounding precision; do not average, pick the convenient number, or silently override discrepancies. If any endpoint cannot be verified, display 'Unavailable — historical endpoints not independently verified'. Never manufacture a value to complete a table.
Calculate in Python/JavaScript from saved evidence: return_pct = (endpoint/reference - 1)*100; round only the final result to two decimals. Verify formula, signs, dates, ticker, exchange, currency, adjustment basis, positive denominator and absence of future rows. Values and commentary must be generated from the same verified evidence. Include audit endpoint dates and prices beside each return or in SOURCES & DATA so readers can reproduce it.
A daily quote's verification does not establish the historical return's verification. Any failed historical check withdraws that specific return and any trend explanation dependent on it.
Before publishing, automatically compare every displayed historical return to its evidence calculation within 0.005 percentage points; fail the build or replace the value with Unavailable if missing/mismatched. No numeric 30D/1Y figure may be published without passing this gate.
For corrections explicitly state what was withdrawn/corrected and the reason. Update today's dated edition and latest edition together, preserving older archives. Regenerate both HTML and PDF from matching corrected content and verify the successful deployment. Never claim numeric returns corrected when they have only been withdrawn.
